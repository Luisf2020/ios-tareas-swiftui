# ios-tareas-swiftui

App SwiftUI de tareas: estado con @State, bindings y preview de Xcode.

> Proyecto de portafolio de Luis Felipe Zuniga Leon. Desarrollado con asistencia de IA
> (generacion de codigo, revision y documentacion); el codigo fue revisado y probado manualmente.
> No declara clientes, metricas ni resultados no verificables.

## Stack

- Swift
- SwiftUI
- iOS

## Como ejecutar

```bash
# Abrir TasksApp/ en Xcode y ejecutar en el simulador
```

## Estructura

```
TasksApp/ContentView.swift  # pantalla
TasksApp/Tarea.swift        # modelo
```

## Notas

No incluye proyecto Xcode completo (`.xcodeproj`); las fuentes estan listas para integrarlas en un proyecto SwiftUI nuevo.
